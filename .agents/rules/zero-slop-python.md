# Python Zero-Slop Engineering Rules

1. **Schema-First (Pydantic v2 / Dataclasses):**
   - Все структуры запросов, ответов, конфигураций и состояний БД описываются через `pydantic.BaseModel` с жесткой валидацией (`Field(...)`, `ConfigDict(extra='forbid')`).
   - Запрещено передавать неструктурированные `dict[str, Any]` между слоями архитектуры.
2. **Полная типизация сигнатур:**
   - Каждая функция и метод обязаны иметь аннотации всех аргументов и явный тип возвращаемого значения (`-> ReturnType`).
   - Использование `Any` и `# type: ignore` запрещено и блокируется хуком `PostToolUse`.
3. **Явная обработка ошибок и ресурсов:**
   - Запрещены пустые или обобщенные перехваты `except Exception: pass`.
   - Все операции с таймзонами обязаны использовать стандартный `zoneinfo.ZoneInfo` (например, `ZoneInfo("Europe/Moscow")`), никаких наивных `datetime.now()`.
