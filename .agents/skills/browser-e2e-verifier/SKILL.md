# Протокол Browser-in-the-Loop Verification

Когда необходимо проверить веб-интерфейс или дашборд:

1. Убедись, что локальный сервер запущен в фоновом режиме (`run_command` с `WaitMsBeforeAsync: 3000`).
2. Вызови встроенного браузерного агента (`/browser`) и выполни обязательный чек-лист:
   - Открой URL приложения и дождись рендера DOM.
   - Проверь консоль браузера: количество ошибок `console.error` и `Uncaught ReferenceError/TypeError` должно быть строго равно **0**.
   - Проверь вкладку Network: все API-запросы инициализации (`/api/...`) должны вернуть статус `200 OK`.
   - Выполни интерактивное действие по ТЗ (добавление записи через форму, переключение фильтра, клик по кнопке теста) и убедись, что UI обновился реактивно.
   - Сделай финальный скриншот состояния страницы и сохрани ссылку на него в Артефакт `Verification Walkthrough`.
